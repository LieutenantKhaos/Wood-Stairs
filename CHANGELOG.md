# Changelog

## 1.1.0 — Minecraft 26.3 / Fabric

- Updated Minecraft, Fabric Loader, and Fabric API dependencies for 26.3.
- Both built-in resource packs use resource format 97.1.
- Existing block IDs, recipes, shapes, and wood families retained.


## 1.0.0 — Minecraft 26.2 / Fabric

- Consistent plank tops and vertical risers across vanilla and Biomes O' Plenty wood stairs.
- Shared straight, inner, and outer stair geometry.
- Optional built-in Wood Stairs (Alternative) pack with bark risers.
- Existing Programmer Art pack retained.
- Source and Gradle build restored from the supplied compiled mod.

## Repository layout

- Mod downloads are distributed through GitHub Releases.
- Previous JARs and supplied archives remain available in Git history.
- Labeled comparison renders are under docs/images.
- Blockbench project files are excluded.
