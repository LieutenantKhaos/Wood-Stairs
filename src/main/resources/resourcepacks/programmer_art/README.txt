Wood Stairs (Programmer Art) (built-in resource pack)

This directory is packaged inside the mod JAR at resourcepacks/programmer_art.
Fabric registers it as an optional NORMAL built-in pack named "Wood Stairs (Programmer Art)".
It should appear in Options -> Resource Packs under Available.

This compatibility layer contains the Wood Stairs vanilla-family model overrides.
Enable Minecraft's built-in Programmer Art pack as well; the models intentionally reference
minecraft:* texture IDs so Minecraft's Programmer Art assets provide the classic pixels.
